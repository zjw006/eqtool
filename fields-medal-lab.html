迈克尔·阿蒂亚 · 1966年菲尔兹奖 · 阿蒂亚-辛格指标定理

拓扑绝缘体：里面不导电，边缘疯狂导电

应用：下一代量子计算机的"抗干扰导线"
拓扑绝缘体

动画在演示什么？

黄色箭头是电子。拓扑绝缘体内部是绝缘的（电子不动），但边缘上的电子只能单向狂奔，遇到杂质也绝不回头——这就是指标定理保证的"拓扑保护"。切换成普通材料，边缘电子立刻被杂质撞得四散反弹。

现实对应：手机芯片发热、量子比特怕干扰，都因为电子会被杂质"撞回去"。拓扑边缘态不发热、抗干扰，是拓扑量子计算机的数学根基。

丘成桐 · 1982年菲尔兹奖 · 卡拉比-丘流形

被藏起来的六个维度：弦理论的"折叠空间"

应用：超弦理论 / 粒子物理标准模型
蜷缩褶皱数5 重褶皱

动画在演示什么？

弦理论说：我们的宇宙除了长宽高山时间，还有六个维度——但它们没有消失，而是被"揉"成了这种极度褶皱的微小形状，尺度比原子还小亿亿倍。丘成桐证明了这种形状确实存在，弦理论才有了立足之地。拖动滑杆，改变它的褶皱方式。

现实对应：粒子的种类、质量、相互作用强度，都由这个"隐藏形状"的几何决定——我们观测到的四维物理定律，是它的投影。

丘成桐 · 1982年菲尔兹奖 · 正质量猜想

引力弹弓：质量如何弯曲时空

应用：引力波探测 / 航天器轨道设计
天体质量拖动金色天体试试

动画在演示什么？

网格是时空本身，金色天体把它"压"出了凹陷——引力的本质就是时空的弯曲。小球不是被"吸"过去，而是沿着弯曲时空里的直线滚落。正质量猜想证明了：这个凹陷永远朝下，宇宙不会凭空塌出负能量。用鼠标拖动天体，看小球轨道如何变化。

现实对应：航天器借助行星引力"弹弓"加速（旅行者号、嫦娥工程），以及LIGO探测引力波的数据分析，都以这套几何理论为地基。

佩雷尔曼（2006年拒领）· 庞加莱猜想 / 里奇流

把任何形状的气球"熨"成标准球面

应用：宇宙空间形状分类
圆度偏差: —

左图是一个奇形怪状的闭合曲面（的截面）。里奇流像一台数学熨斗：凹的地方填平，凸的地方压回去，任何"简单连通"的形状最终都会被熨成一个完美的圆。佩雷尔曼用这个思想证明了：三维中所有这样的空间，本质上都是球面。

现实对应：宇宙学家据此分类宇宙大尺度结构的可能形状；同样的"曲率流"算法也被用于医学影像的器官表面重建。

爱德华·威滕 · 1990年菲尔兹奖 · 拓扑量子场论

把信息编成"辫子"：剪不断的量子记忆

应用：拓扑量子计算机（微软Majorana路线）
已编织 0 次

动画在演示什么？

两个"任意子"（准粒子）每交换一次位置，它们的运动轨迹就在时空中打一个交叉。多点几次——下方的辫子图样就是存储的信息。关键在：信息不在粒子上，而在结的拓扑花样里，局部干扰碰不到它，除非你亲手把辫子解开。

现实对应：这就是拓扑量子计算：普通量子比特怕一丁点噪声，而"辫子比特"天生抗干扰——威滕的场论为它提供了数学框架。

拉尔斯·赫尔曼德尔 · 1962年菲尔兹奖 · 偏微分方程一般理论

飞机为什么能飞：气流绕过机翼

应用：计算流体力学（CFD）设计飞机与天气预报
风速 机翼迎角 升力 ↑

动画在演示什么？

每条流线都是偏微分方程的数值解。拖动"迎角"滑杆，你会看到机翼上方的流线被压缩变密（流速快、压强低），下方流速慢——压强差就是升力。迎角过大，流线分离（乱流），升力骤降，这就是"失速"。

现实对应：每一架飞机上天前，都要在计算机里用这套方程"试飞"几万次；你手机里的天气预报App，解的也是同一族方程。

皮埃尔-路易·利翁 · 1994年菲尔兹奖 · 粘性解理论

没有事故，为什么也会堵车？—— 幽灵堵车

应用：交通流模型 / 高超声速流体
车辆密度55 辆车

动画在演示什么？

环形公路上的每辆车只遵守三条简单规则：能快则快、前车近了刹车、偶尔犯迷糊。密度一大，你会看到红黄色的"堵车冲击波"自发形成，并且向后传播——明明没有任何事故。这种"激波"的数学严格解，正是利翁的粘性解理论给出的。

现实对应：高速交警用这套模型预测幽灵堵车；同一类方程描述战斗机激波、火箭尾焰——从五环堵车到马赫数10，是同一套数学。

维拉尼（2010）· 玻尔兹曼方程严格解 ｜ 邓煜等（2025）· 希尔伯特第六问题

从杂乱无章到钟形曲线：气体如何"自发有序"

应用：核聚变等离子体 / 航天器再入大气
混乱度 ↓

所有小球起初挤在左半边、速度整齐划一。碰撞、碰撞、再碰撞……右图的速度分布直方图会自动长成一条光滑的钟形曲线（麦克斯韦分布）。维拉尼严格证明了这个过程必然发生；邓煜等人则打通了"牛顿力学→流体方程"的最后一环。

现实对应：核聚变装置里上亿度的等离子体怎么控制、返回舱再入大气时有多热，都靠这套动理学理论计算。

皮埃尔·德利涅 · 1978年菲尔兹奖 · 韦伊猜想

椭圆曲线上的"加法"：保护你网银的数学体操

应用：椭圆曲线密码（ECC）— HTTPS / 手机银行 / 区块链
连续跳点 已跳 0 步

动画在演示什么？

曲线上的两个点 P、Q 连成一条直线，与曲线交出第三个点，翻转到对称位置就是 R = P+Q。从P出发反复"加自己"，点会在曲线上毫无规律地乱跳。正向跳12步只要一瞬间；但给你终点，反推跳了几步，超级计算机也算不出来——这就是你账户安全的来源。

现实对应：你浏览器地址栏的小锁🔒、微信支付的密钥、比特币签名，背后都是这条曲线上"好算难猜"的加法。

安德鲁·怀尔斯 · 1998年特别奖 · 费马大定理

xⁿ+yⁿ=zⁿ：一个358年无人破解的"禁区"

应用：代数几何工具 → 现代密码协议
指数 nn = 2

动画在演示什么？

曲线 xⁿ+yⁿ=13ⁿ 穿过整数格点（白点）时，就对应一组整数解。n=2 时绿点扎堆——勾股数 5²+12²=13²；把滑杆推到 n=3 以上，曲线上一个整数点都找不到。怀尔斯用椭圆曲线和模形式证明了：n≥3 永远没有解。

现实对应：证明过程中诞生的代数几何工具，如今是椭圆曲线密码协议的设计语言——保护着你的每一次支付。

雨果·迪米尼-科潘 · 2022年菲尔兹奖 · 相变概率理论

磁铁为什么突然"失磁"：亲眼见证相变

应用：合金、液晶、超导材料的临界温度预测
🧊 温度 T = 1.5 磁化强度: —

动画在演示什么？

每个小方块是一个微型磁针（金=朝上，蓝=朝下），它总想和邻居保持一致，但温度会捣乱。慢慢拖动温度滑杆：低温时全体颜色统一（铁磁体）；温度升到 T≈2.27 附近，秩序突然崩溃、变成花屏（顺磁体）——这个突变点就是"相变"，和水在100°C突然沸腾一模一样。

现实对应：磁铁加热到770°C突然失磁、超导材料降温到某点突然零电阻——材料学家用这套理论精确计算每种新材料的"突变温度"。

斯坦尼斯拉夫·斯米尔诺夫 · 2010年菲尔兹奖 · 共形不变性

渗流：水什么时候能渗透整块海绵？

应用：多孔材料 / 复合材料 / 电网可靠性
孔隙连通概率 pp = 0.50

动画在演示什么？

每个小格以概率 p "打通"。慢慢拖大 p：在 p≈0.59 附近，金色区域会突然从左岸贯通到右岸——又是一个相变点！斯米尔诺夫严格证明了此时渗流曲线具有"共形不变性"：无论怎么拉伸旋转，统计规律不变。

现实对应：石油在多孔岩层里的开采、咖啡萃取、锂电池隔膜设计、疫情在网络上的传播阈值，都是渗流问题。

西蒙·唐纳森 · 1986年菲尔兹奖 · 四维流形拓扑

亲手"转动"一个四维超立方体

应用：四维空间几何 / 量子材料分类
XW 面旋转ZW 面旋转自动旋转中

动画在演示什么？

三维生物永远看不到四维物体，只能看它的"影子"——就像球在纸上的影子是圆。屏幕上是四维超立方体（16个顶点、32条棱）在三维中的投影。拖动滑杆，亲手在第四个维度里转动它：看它"里外翻转"，那是投影穿过了自身。唐纳森发现：四维空间藏着其他维度没有的"怪异"结构。

现实对应：拓扑物态的分类高度依赖空间维度的几何性质；四维拓扑的怪异发现，持续启发新型量子材料研究。

阿莱西奥·菲加利 · 2018年菲尔兹奖 · 最优运输理论

把一堆沙子变成一张笑脸：AI生图的数学心脏

应用：生成式AI（GAN / 扩散模型）、图像风格迁移
运输进度 0%

动画在演示什么？

左边是一堆随机乱点的噪声，目标是一张笑脸。每个点都找到了"花最少力气走到目标位置"的路径——这就是最优运输。AI生成图片做的事一模一样：从噪声出发，一步步"搬运"成一张逼真的人脸。

现实对应：Wasserstein GAN 让AI画图不再崩坏；医学影像配准（把两次CT扫描对齐）用的也是同一套"搬运"理论。

洛朗·施瓦茨 · 1950年菲尔兹奖 · 分布理论

一堆圆转出方波：傅里叶的魔法齿轮

应用：信号处理 / 图像压缩 / 医学影像
圆的数量（谐波数）3 个谐波

动画在演示什么？

每个圆都在匀速转动，首尾相接像一串齿轮。最末端那个点画出的轨迹（右侧）——圆加得越多，越接近一个方方正正的方波！这就是傅里叶级数：任何信号都能拆成一堆简单圆周运动。施瓦茨的分布理论，让这套拆解在数学上彻底严格。

现实对应：MP3压缩、JPEG图片、手机信号、CT图像重建——全都是"拆成圆再拼回去"的傅里叶思想。

王虹等（2025）· 挂谷猜想 ｜ 射线变换理论

CT是怎么"看穿"你的？—— 从投影反推内部

应用：CT / MRI / 雷达图像重建
扫描角度: 0°

动画在演示什么？

左边是"患者"（骨头+一个病灶）。X光从各个角度穿过，只记录每条射线的总衰减（中间的投影图）。神奇的是：把足够多角度的一维投影"反抹"回去，右边的内部结构就从无到有地浮现了。能从多稀疏的数据中重建多清晰的图像，正是挂谷猜想这类理论回答的精度极限。

现实对应：医院CT、安检机、相控阵雷达、射电望远镜，全部建立在"射线变换"的数学反演之上。

马丁·海尔 · 2014年菲尔兹奖 · 正则性结构

乱中生长的界面：火焰、细菌与股价

应用：随机生长 / 湍流 / 金融波动建模
粗糙度 w = —

动画在演示什么？

金色"天际线"在随机生长——每一列随机增高，又会被邻居拉平一点。既随机又有规则，这就是KPZ方程描述的世界：它的解"粗糙到连微积分都失灵"，海尔发明的正则性结构第一次让它有了严格意义。下方的粗糙度 w 会稳定按幂律增长。

现实对应：火焰前沿、细菌菌落边缘、肿瘤边界、材料镀层生长，甚至股价波动，都被证明属于同一个"KPZ普适类"。

斯蒂芬·斯梅尔 · 1966年菲尔兹奖 · 动力系统（"马蹄"模型）

蝴蝶效应：差之毫厘，谬以千里

应用：天气预报的极限、电路设计、轨道稳定性
初始角度差（度） 0.01°

动画在演示什么？

两个几乎一模一样的双摆同时释放——初始角度只差 0.01°。前几秒它们完全重合（看起来只有一个）；几秒后轨迹突然分道扬镳。这就是混沌：初始条件的微小差别被指数级放大。把滑杆调到0，它们会永远同步。

现实对应：这就是为什么天气预报超过两周必然不准；也是航天器轨道计算、神经元放电、心律分析必须面对的数学现实。

米尔诺 / 托姆 · 菲尔兹奖 · 微分拓扑与配边理论

机械臂的"姿势空间"：动鼠标指挥它

应用：机器人运动规划 / 逆运动学
🖱 把鼠标移进画面，机械臂会来够你

动画在演示什么？

移动鼠标，两节机械臂会实时解算两个关节角去"够"你的指尖。注意灰色圆环——那是它能够到的所有位置（工作空间）。所有可能的"姿势"本身构成一个甜甜圈形状的曲面（环面 T²）：机器人在里面规划路径，用的就是微分拓扑的语言。

现实对应：工厂机械臂避障、手术机器人达芬奇、火星车的机械臂，路径规划都在各自的"构型空间"里做拓扑计算。

斯蒂芬·斯梅尔 · 1966年菲尔兹奖 · 数理经济学

菜市场的价格是怎么"自动"找到的？

应用：市场均衡理论 / 机制设计
价格收敛中…

动画在演示什么？

蓝线是需求（越贵买的人越少），金线是供给（越贵卖的人越多）。白点是当前价格：贵了→卖不动→降价；便宜了→抢光→涨价。不需要任何人指挥，价格自己找到交点。点按钮制造一次需求冲击，看市场如何震荡后重新找到新均衡。

现实对应：斯梅尔用动力系统严格证明了均衡价格的存在与稳定——从股票撮合、网约车动态定价到碳交易市场，都建立在这类均衡理论上。
