# 碳途纪元 · 2D 网页版

`godot/` 里那套 **2D 伪透视跑酷**的浏览器移植（纯 Canvas2D + Web Audio，无依赖、无构建、无素材）。
**不是** `web-v2.4/`（那是已冻结的 Three.js 原版，只读）。

## 怎么玩

直接双击 `index.html`（或拖进浏览器）。无需服务器、无需安装。

| 操作 | 键盘 | 触屏 |
|---|---|---|
| 换道 | ← / → 或 A / D | 左右滑动，或点底部 ‹ › |
| 下滑成键 | ↓ / S | 向下滑动，或点底部 ↓ |
| 开始 / 重开 | Enter / 空格 | 点按钮 |
| 暂停 / 继续 | Esc / P（Esc 再按继续） | 点右上 Ⅱ |
| 静音 / 开声 | M | 点右上 ♪ |
| 返回 | Esc（暂停后） | 结算页右上 ✕ 或「返回关卡选择」 |

流程：关卡选择 → 关卡介绍页（原子级结构图 + 科普文案）→ 点开始 → 3、2、1 倒计时 → 开跑。
凑齐目标分子撞进分子门交付，达到本关交付次数即通关；进度（解锁 / 每关最佳 / 静音状态）存在 `localStorage`。

## 音频（全部程序化合成，零音频文件）

`audio.js` 用 Web Audio 现算，不加载任何素材：

| 事件 | 声音构成 |
|---|---|
| 成键 | 三角波 + 根音正弦的短 pluck，**音高随链长上升**；叠一小段高频噪声 click |
| 记满链 | 小三和弦分解（C5-E5-G5）+ 高频 whoosh |
| 交付 | 四音上行（C5-E5-G5-C6，正弦 + 三角泛音）+ 带通扫频 whoosh |
| 过关 | 五音上行琶音 |
| 撞墙 / 湮灭 | 打击三层：低频 thump（150→42 Hz）+ 中频 crack（带通噪声）+ 高频 swish |
| 撞碎模块 | 同三层但更短更轻（220→90 Hz） |
| 倒计时 / UI | 短正弦 tick / 方波 click |

**背景音**：84 BPM，Am–F–C–G 四小节循环 —— 失谐锯齿 pad（低通 620–1060 Hz，第 0 档就有根音+五度）、
**低音线**（每小节根音低八度，55Hz 起，低通 220Hz）、心跳 kick（1、3 拍）、八分沙锤（高通 7.2 kHz）；
每 2 次交付**升一档**（0→2）：一档加五声音阶点缀，二档 pad 叠满三音。
音乐总线 0.80、全部走 `DynamicsCompressor` 收口，避免叠加爆音。

**什么时候开始响**：第一次点击/按键就起 BGM（`unlockAudio()`），所以关卡选择页也有背景音，
不必先进关卡。菜单底部会显示「♪ 背景音已开启 · 按 M 或点右上 ♪ 静音」。
想核对"到底有没有声"，在真实浏览器里打开 `audio-signal.html`：它会离线渲染 3 秒 BGM 并显示 RMS/峰值。

浏览器自动播放策略：`AudioContext` 在**第一次点击/按键**时才创建（`unlockAudio()`），
之后再点 ♪ 或按 M 静音，状态记在 `localStorage`。

## 移植了什么

- **投影**：与 `godot/scripts/space2d.gd` 同一套公式（R=1000、F_PX=780、Y_HORIZON=576、B_CAM=14），
  画布 720×1440（10:20），窗口按 `keep` 等比缩放 + 黑边。
- **判定**：成键窗口前 3.0 / 后 2.0 u、缓冲 0.20s、原子避墙 7u、墙间距 20u 规则、
  交付按**多重集**比对（与 D-32 一致）。
- **节奏（D-59）**：`_difficulty() = dist/240` 插值 —— 墙 44–58 → 26–34 u，模块 9.5–14 → 15–21.5 u；
  速度 25 → 35（每 3 次交付 +1.5）。
- **13 关**：名称/分子式/模块/目标次数/介绍文案/原子级结构图（1–9 关）全部从 `godot/data/levels.json` 导出。
- **表现**：天空下亮上暗、地平线亮边 + bloom + 空气透视、远山/近山、两侧向后飘的圆片（跟当关墙同色）、
  主角滚纹（向上翻）+ 拖尾、成键/交付/湮灭的大字提示、碎块/火星/冲击波、暂停页。

## 和 Godot 版的差异（有意简化）

- 路面母题只画第 1 关的水波纹，其它关用同一套（Godot 版是 13 种）。
- 折叠动画（`fold`）没有移植，交付直接 +1。
- 音频是网页版自己合成的版本，音色与 `sfx_synth.gd` 不完全一致（事件与节奏对齐）。
- 关卡墙的"菱形"用纯 Canvas 多边形重画，没有 3D 感的分面。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 入口（canvas + 全屏布局） |
| `game.js` | 全部游戏逻辑与绘制（约 1550 行） |
| `audio.js` | 程序化音效与 BGM（Web Audio，无素材） |
| `data.js` | **自动导出**的关卡数据（来自 `godot/data/levels.json`，勿手改） |
| `selftest.js` | Node 端游戏自检：假 DOM 跑 `?selftest=1`，验证换道/成键/多重集/交付/撞墙/难度爬坡 |
| `audio-test.js` | Node 端音频自检：假 AudioContext 数节点，验证音效与 BGM 结构（13 项） |
| `audio-signal.html` | 手动核对页：真实浏览器里离线渲染 3s BGM 并显示 RMS/峰值 |

## 自检

```bash
node selftest.js       # 期望 7/7 passed
node audio-test.js     # 期望 13/13 passed
```
